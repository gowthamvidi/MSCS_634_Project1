# MSCS_634_Project1

## Project Overview

This repository contains the deliverables for **MSCS 634 – Residency Project**. The project demonstrates the complete data science workflow, including data collection, data preprocessing, exploratory data analysis, regression modeling, classification, clustering, pattern mining, and final business recommendations.

The repository is organized into four deliverables corresponding to each residency day.
