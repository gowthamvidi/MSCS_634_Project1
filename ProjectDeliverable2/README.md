## Project Overview

This project uses the cleaned **Online Shoppers Purchasing Intention** dataset to build regression models that estimate **`ProductRelated_Duration`**, the time a visitor spends on product-related pages during an online shopping session.

The cleaned dataset contains **12,205 sessions and 18 original attributes**. It includes page counts, page durations, bounce and exit rates, month, visitor type, traffic source, device-related categories, weekend status, page value, and purchase outcome. The dataset is suitable for this project because it contains a continuous engagement variable, a large number of observations, mixed numerical and categorical predictors, and meaningful customer-behavior features.

Although the original dataset is frequently used for purchase classification, this project reframes it as a regression task to answer the following question:

> How accurately can session characteristics predict the duration of product-page engagement?

## Data Preparation and Leakage Prevention

The regression target is `ProductRelated_Duration`. The fields `Revenue` and `PageValues` were removed from the predictors because they are post-session outcomes that could create information leakage. The notebook uses an 80/20 train-test split with `random_state=42`. Five-fold shuffled cross-validation is performed only on the training portion, leaving the test set untouched for final evaluation.

The preprocessing pipeline handles mixed data types by:

- imputing numerical features with the median;
- standardizing numerical features;
- imputing categorical features with the most frequent category; and
- one-hot encoding categorical variables while handling unseen categories.

## Feature Engineering

The following features were created to improve behavioral representation and model interpretability:

- `TotalPageCount`
- `NonProductPageCount`
- `NonProductDuration`
- `AvgAdministrativeTime`
- `AvgInformationalTime`
- `ProductPageShare`
- `EngagementScore`
- `BounceExitGap`
- `SpecialDayWeekend`
- `MonthNumber`
- `Quarter`
- log-transformed versions of skewed page-count and duration predictors

No engineered feature uses `ProductRelated_Duration`, so the feature-engineering process does not leak target information.

## Regression Models

Three models were evaluated:

1. **Multiple Linear Regression** with a `log1p` target transformation.
2. **Ridge Regression** with `alpha=0.10` and a `log1p` target transformation.
3. **Random Forest Regression** with 200 trees, maximum depth 18, and minimum leaf size 2.

The log-target transformation was used for the linear models because `ProductRelated_Duration` is highly right-skewed and contains several extremely long browsing sessions.

## Best Model

**Multiple Linear Regression** was selected as the final model because it achieved the strongest performance on the untouched test set:

- **R² = 0.7590**
- **MSE = 1,104,214.44**
- **RMSE = 1,050.82**

This means the model explained approximately **75.9% of the variation** in product-related browsing duration in the final holdout sample. Ridge Regression performed almost identically, with an RMSE only 2.82 units higher, indicating that regularization did not materially improve final test performance.

Random Forest produced the best average cross-validation scores but performed less effectively on the final test set. The test target had a larger standard deviation and contained the dataset's longest session, approximately 63,974 duration units, while the longest training observation was approximately 43,171. This extreme unseen session increased squared-error metrics and illustrates that Random Forest was more sensitive to unusually long holdout observations.

## Meaningful Insights

- Product-page count and its log-transformed version were among the most influential predictors of product-page duration.
- Bounce rate, exit rate, and the engineered engagement score contributed useful information about session quality.
- Log transformation helped linear models manage the strong right skew of engagement duration.
- Similar test and cross-validation results for the selected linear model indicate reasonable generalization.
- Residual errors became larger for exceptionally long sessions, showing that extreme engagement remains difficult to predict with session-summary data alone.
- Ridge and ordinary multiple regression performed nearly the same, suggesting that severe overfitting from coefficient size was not the primary limitation.

## Challenges and Solutions

### 1. Highly Skewed Target

**Challenge:** A small number of sessions had extremely large product-page durations, which could dominate MSE and RMSE.

**Solution:** The linear and Ridge models were trained on `log1p(ProductRelated_Duration)` and predictions were transformed back to the original scale. Log-transformed predictor features were also created.

### 2. Mixed Numerical and Categorical Features

**Challenge:** The dataset includes continuous values, integer-coded categories, text categories, and Boolean fields.

**Solution:** A `ColumnTransformer` and scikit-learn pipelines were used to ensure consistent imputation, scaling, and one-hot encoding within every training and cross-validation fold.

### 3. Potential Data Leakage

**Challenge:** `Revenue` and `PageValues` are strongly connected to final shopping outcomes and might reveal information unavailable during an earlier engagement prediction.

**Solution:** Both variables were excluded before training and cross-validation.

### 4. Extreme Holdout Sessions

**Challenge:** The test split contained a more extreme maximum duration than the training set, increasing final RMSE and reducing Random Forest holdout performance.

**Solution:** Results were interpreted using both five-fold cross-validation and the final test set. The notebook also includes residual and actual-versus-predicted plots to make this limitation visible.

### 5. Reproducibility

**Challenge:** Random data splitting and ensemble training can generate different results across runs.

**Solution:** `random_state=42` is used for the train-test split, cross-validation strategy, and Random Forest model.
